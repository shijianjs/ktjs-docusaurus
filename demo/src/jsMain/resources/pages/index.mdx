<ktjs-features section-title="Why this project" tinted>

<ktjs-feature icon="lucide:file-code-2" title="Configuration is Kotlin">The site config, the theme config and the sidebars are typed Kotlin values; a misspelt field is a compile error, not a validation message at build time.</ktjs-feature>

<ktjs-feature icon="lucide:package" title="No npm project to maintain">Versions live in one package.json for Dependabot, node_modules is installed by the Kotlin/JS workspace, and the Docusaurus CLI is invoked by Gradle.</ktjs-feature>

<ktjs-feature icon="lucide:folder-tree" title="Markdown stays Markdown">Pages live under src/jsMain/resources and are copied next to the compiled Kotlin. Prose does not need a component tree.</ktjs-feature>

<ktjs-feature icon="lucide:blocks" title="A kit for the rest">Home sections and the TOC toggle are written against the DOM, so they work in a Markdown-only site and drag no component runtime along.</ktjs-feature>

</ktjs-features>
