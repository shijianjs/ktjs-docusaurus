<ktjs-features section-title="为什么用它" tinted>

<ktjs-feature icon="lucide:file-code-2" title="配置就是 Kotlin">站点配置、主题配置、侧边栏都是带类型的 Kotlin 值；字段拼错是编译错误，不是构建期的校验提示。</ktjs-feature>

<ktjs-feature icon="lucide:package" title="没有要维护的 npm 工程">版本集中在一个 package.json 里交给 Dependabot，node_modules 由 Kotlin/JS 工作区安装，Docusaurus CLI 由 Gradle 调用。</ktjs-feature>

<ktjs-feature icon="lucide:folder-tree" title="Markdown 还是 Markdown">页面放在 src/jsMain/resources 下，和编译产物一起拷进站点；正文不需要组件树。</ktjs-feature>

<ktjs-feature icon="lucide:blocks" title="其余的交给工具箱">首页分区和目录折叠都直接对着 DOM 写，纯 Markdown 站点也能用，不拖一套组件运行时进来。</ktjs-feature>

</ktjs-features>
